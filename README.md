# Оптимизация структуры энергосистемы

Дополнительное задание по дисциплине «Системы поддержки принятия решений».

Ноутбук [`SPPR_extra_energy_efficiency.ipynb`](SPPR_extra_energy_efficiency.ipynb) содержит текст § 3 «Применение линейного программирования к энергетике» с предоставленных страниц 60–63, учебный пример для пяти типов станций и решение в Pyomo/HiGHS.

Исходная цель минимизации эксплуатационных расходов заменена максимизацией отношения годовой выработки к затратам на строительство. Выполнено преобразование Чарнса–Купера; прямая и двойственная ЛП построены и решены отдельно. Проверены допустимость, дополняющая нежёсткость и равенство целевых функций.

Числа примера синтетические и воспроизводимые; данные конкретных электростанций не используются. Рассматривается непрерывная модель, но её оптимальный план для выбранных данных целый: 2 ТЭЦ, 3 ВЭС и 2 СЭС. Обе целевые функции равны **341/130 ≈ 2,6230769231 ГВт·ч/год на 1 млн долл. строительства**.

## Запуск

Проверено на Python 3.12. Рекомендуется отдельное виртуальное окружение.

```bash
python -m pip install pyomo highspy numpy pandas matplotlib jupyterlab
python -m jupyter lab SPPR_extra_energy_efficiency.ipynb
```

В JupyterLab выберите **Kernel → Restart Kernel and Run All Cells**. Основной решатель — `appsi_highs`, предусмотрены альтернативы `highs` и установленный CBC. Результаты сохранены в ноутбуке; для выполнения не требуются исходные скриншоты или сеть.
